# Guía interactiva de correlación y regresión lineal

Material de estudio para practicar correlación y regresión lineal con calculadoras Casio. Incluye recorridos guiados para ClassWiz X/EX, ES/ES PLUS, MS y ClassWiz CW, el desarrollo manual del Ejercicio 12, simuladores y un banco de ejercicios del TP 6.

## Usar la guía

Abrí `index.html` en un navegador moderno o visitá la versión publicada en GitHub Pages. No requiere conexión una vez descargada, ni instalación, cuentas, Node.js, npm, frameworks o dependencias.

1. Elegí un conjunto de datos y tu familia de calculadora.
2. En **Modo práctica**, indicá si necesitás la recta, `r`, `R²`, sumatorias o una predicción.
3. Intentá resolver la misión en tu calculadora. Usá las ayudas graduales: pista, menú y ruta completa.
4. Si perdés el hilo, elegí **Estoy perdido** para volver al primer paso de tu modelo.
5. Usá **Imprimir resumen de este modelo** para guardar una guía breve configurada con tu selección actual.

La guía muestra nombres de teclas y pantallas de referencia. Entre variantes de una misma familia pueden cambiar números de menú o etiquetas; seguí siempre lo que indique la pantalla de tu calculadora.

## Funciones incluidas

- Guías paso a paso para cuatro familias de Casio.
- Selector de objetivo que muestra solo los pasos necesarios.
- Práctica guiada con revelación progresiva de pistas.
- Indicador de compatibilidad según el modelo seleccionado.
- Desarrollo manual de la recta de regresión y simuladores de predicción.
- Banco de 12 ejercicios del TP 6.

## Estructura

- `index.html`: contenido, accesibilidad básica y estructura.
- `css/styles.css`: estilos locales y reglas de impresión.
- `js/datos.js`: conjuntos de datos de ejemplo.
- `js/app.js`: interacción, simuladores, práctica y filtros de pasos.

## Editar o publicar

Editá los archivos directamente y recargá el navegador. No hay compilación ni paquetes que instalar.

Para GitHub Pages, subí el contenido de esta carpeta a la raíz del repositorio y configurá **Settings → Pages → Deploy from a branch → main → /(root)**. Antes de publicar, revisá datos personales, créditos y compatibilidad de los modelos.
